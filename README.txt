# Online Portfolio — Priya Ranjan Kumar

## Before publishing
1. Open `index.html` in a text editor.
2. Replace `YOUR_EMAIL@example.com` with your preferred professional email address.
3. Review all experience figures and wording for accuracy.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com
2. Create a new public repository named `yourusername.github.io` (replace `yourusername` with your GitHub username).
3. Upload `index.html` to the repository root.
4. In repository Settings → Pages, choose deployment from the `main` branch and `/ (root)`.
5. GitHub will publish the site at `https://yourusername.github.io` after deployment completes.

## Alternative: Netlify
Visit https://app.netlify.com/drop and drag the folder containing `index.html` into the drop area. Netlify will provide a public URL. You can customize the URL in your Netlify site settings if the name is available.

Note: This package creates the website files; it does not itself publish a public URL. Publishing requires signing in to a hosting service.
